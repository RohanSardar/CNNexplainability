# 🧠 CNN Explainability

<img width="1100" height="254" alt="1_YXVal5Z8isPZsWASF_oH_g" src="https://github.com/user-attachments/assets/3ea070bd-cead-4b2d-aaba-568aa4e2a873" />

This repository contains implementations of popular **CNN explainability techniques** such as CAM, Grad-CAM, Grad-CAM++, and more. The goal is to make it easy to visualize what parts of an image a convolutional neural network focuses on when making predictions.

At the moment, **only Class Activation Mapping (CAM)** is implemented.
More methods — including **Grad-CAM**, **Grad-CAM++**, **Score-CAM**, and others — will be added soon.

## 🚧 Project Status

This project is **a work in progress**.
Expect frequent updates as new explainability techniques are added.
<br>I wrote a **Medium** article on it [see here](https://rohan-sardar.medium.com/visualizing-resnet18-attention-with-class-activation-mapping-cam-in-pytorch-5c0b56d3f246).

## 🖼️ Class Activation Mapping (CAM)

CAM highlights the image regions that contribute most to a model’s prediction.
Explore `class_activation_mapping.ipynb`
